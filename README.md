# PROJETO-BUBBLESORT
Sistema em Java que lê 1.000.000 de empresas do arquivo Empresas_BubbleSort.txt, ordena pelo valor de mercado (maior para o menor) com Bubble Sort otimizado e grava o resultado em Empresas_Ordenadas.txt. Inclui testes automáticos e documentação. Integrantes: Jarlisson Brito Santos, Brunno Passos e Luiz Gustavo.
