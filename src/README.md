# 📦 src – Código-fonte

| Arquivo | Descrição |
|---|---|
| `Empresa.java` | Modelo de um registro. Converte o valor de mercado para centavos (`long`). |
| `BubbleSort.java` | Bubble Sort decrescente com parada antecipada e limite da última troca. Conta passadas, comparações e trocas. |
| `ArquivoEmpresas.java` | Lê o TXT (ignorando linhas vazias ou inválidas) e grava o resultado no mesmo formato. |
| `Main.java` | Executa a leitura, a ordenação e a gravação, mostrando os tempos e as 5 maiores e 5 menores empresas. |
| `TesteBubbleSort.java` | Testes automáticos sem bibliotecas externas. |

Uso do programa principal: `java Main [entrada] [saida] [limite]`
